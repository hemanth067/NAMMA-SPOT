# NammaSpot delivery

This is the Android MVP source. The included GitHub Actions workflow builds an installable debug APK.

## Build
1. Push this project to a GitHub repository.
2. Open Actions -> Build NammaSpot APK.
3. Run the workflow.
4. Download the `NammaSpot-APK` artifact and install the APK on Android.

## Current MVP
- Home screen
- Nearby service map with demo markers
- Service filters
- Help request screen
- Provider dashboard
- Android location/internet permissions

Provider locations are demo data and must be replaced with verified backend records before customer launch.
